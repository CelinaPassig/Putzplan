⚙️ Einmalige Einrichtung (ca. 10 Minuten)

  1. Öffne Google Drive → Neu → Google Tabelle. Tab unten umbenennen zu Putzplan
  2. Erweiterungen → Apps Script → alles löschen → Code aus apps_script.js einfügen → Speichern
  3. Bereitstellen → Neue Bereitstellung → Web-App → Ausführen als: Ich → Zugriff: Jeder → Bereitstellen
  4. Bei der Google-Warnung: Advanced → "Go to Putzplan (unsafe)" → Allow
  5. Web-App-URL kopieren und hier einfügen:
